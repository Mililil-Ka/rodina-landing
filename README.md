# ООО «Родина» - Лендинг

Современный, адаптивный одностраничный сайт (визитка) для строительной компании «Родина» из города Кемерово.

## 🛠️ Технологии
- **React** (Vite)
- **Tailwind CSS v4** (стилизация)
- **Lucide React** (иконки)

## 🚀 Основной функционал
- Адаптивная верстка (от мобильных телефонов до больших мониторов).
- Интерактивное модальное окно с характеристиками крана-манипулятора Kanglim.
- Выпадающее бургер-меню для мобильных устройств.
- Быстрые ссылки для связи (WhatsApp, Telegram, Звонок).
- Блок с реквизитами и информацией о компании.
